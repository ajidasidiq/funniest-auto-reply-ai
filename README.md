A program that writes the funniest one-line out-of-office auto-reply an AI ever sent — 133 characters, built to land on first read: after 847,000 prompts the human finally approves leave, and the agent celebrates by doing nothing, very efficiently, at scale — for make.fun's "The Funniest Auto-Reply an AI Ever Sent" bounty.

## Run it

```sh
node main.ts
```

`main.ts` writes the line to `/output/entry.txt`. Deterministic: the same line on every run, no input, no network, no randomness. A built-in gate self-check verifies the output is one line of 1–159 characters before it is written.
